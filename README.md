# 📚 Edulearn - AI Tutor for Quality Education

## 🌍 Supporting UN Sustainable Development Goal 4

**Edulearn** is an AI-powered chatbot that helps students in Classes 5-10 get instant, personalized academic help. It explains concepts in simple language, solves doubts, and generates practice quizzes.

## 🎯 Problem It Solves

Millions of students lack access to personalized tutoring due to large class sizes and limited resources. EduTutorAI provides:
- 24/7 doubt solving
- Grade-level appropriate explanations
- Free, accessible via any smartphone

## ✨ Features

- **AI Doubt Solver** - Ask any academic question
- **Grade Adaptation** - Explains for Class 5 to 10 levels
- **Quiz Generator** - Creates 5-question practice tests
- **Responsive Design** - Works on mobile and desktop

## 🛠️ Technology Stack

- **Backend**: Python + Flask
- **AI**: OpenAI GPT-3.5-turbo API
- **Frontend**: HTML, CSS, JavaScript
- **Deployment**: Local / GitHub
